# 🌟 Personal Portfolio Website

Selamat datang di repositori website portofolio profesional saya! Website ini dirancang untuk menampilkan perjalanan karier, proyek-proyek terbaru, dan keahlian saya di bidang **Web Development**, **UI/UX Design**, dan **Edukasi**.

🔗 **Live Demo:** [Lihat Website Saya di Sini](https://maitriyanamettallia.github.io)

## ✨ Fitur Utama (Key Features)

* **🌐 Multi-Language Support:** Dilengkapi dengan fitur penerjemahan langsung (i18n) menggunakan Vanilla JavaScript yang mendukung 3 bahasa: **Indonesia, Inggris, dan Mandarin** tanpa perlu memuat ulang (*reload*) halaman.
* **📱 Fully Responsive Design:** Tampilan antarmuka yang menyesuaikan dengan sempurna di berbagai perangkat (Desktop, Tablet, dan Mobile).
* **🎨 Modern UI/UX:** Menggunakan desain *Glassmorphism* pada navigasi, efek bayangan lembut (*soft-shadows*), animasi *floating*, dan tipografi premium (Poppins Font).
* **⏳ Timeline Resume:** Menampilkan riwayat pengalaman kerja dan organisasi secara kronologis dan terstruktur dengan desain garis waktu yang bersih.
* **⚡ Fast Performance:** Dibangun tanpa *framework* berat untuk memastikan waktu pemuatan halaman (*loading time*) yang sangat cepat.

## 🛠️ Teknologi yang Digunakan (Tech Stack)

* **HTML5:** Struktur semantik website.
* **CSS3:** Styling kustom, animasi CSS (`@keyframes`), Flexbox, dan CSS Grid.
* **JavaScript (Vanilla):** Manipulasi DOM untuk menu responsif (Hamburger Menu) dan logika pergantian bahasa (*Language Switcher*).
* **Font Awesome (v6.0.0):** Ikon vektor untuk UI.
* **Google Fonts:** Tipografi modern menggunakan keluarga font *Poppins*.
